## Share the source

Create a GitHub repository, or use the one already connected in Lovable's Git settings. Extract the ZIP and upload the contents of its top-level folder, so README.md is at the repository root. Keep populated environment files out of Git. Add https://relevantbuy.lovable.app as the repository website. Choose a license before offering reuse rights; none is supplied by this kit.

This export does not create or connect a repository. Lovable Git sync creates a new repository, not a link to an existing one.

## Add the companion videos

Download `unfit_trailer_v4.mp4` and `unfit_readme_walkthrough_v2.mp4` separately and place them in `videos/` beside the README for its relative links to work. The updated source ZIP omits MP4 files; no earlier videos are required.

Alternatively, drag each MP4 into a draft GitHub issue/comment, copy its attachment URL and replace the README links. Inline playback and upload limits depend on GitHub's support; use its displayed limit. Use Releases or external video hosting if needed. Never commit files above GitHub's repository file-size limit.
